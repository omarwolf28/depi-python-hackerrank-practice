# Python – HackerRank Practice

A collection of solutions to exercises from HackerRank's **Python** track, done as part of the
**AI & Data Science** track at **DEPI** (Digital Egypt Pioneers Initiative). Practicing these
problems on HackerRank is what got me to **5 stars** in Python on the platform.

## Contents

The notebook [`python_hackerrank_practice.ipynb`](./python_hackerrank_practice.ipynb) is organized
into five sections:

| Section | Topics |
|---|---|
| Python Basics | I/O, conditionals, loops, functions |
| Data Structures & Comprehensions | lists, list comprehensions, nested lists, dictionaries |
| Closures & Decorators | function wrappers, `@decorator` syntax |
| NumPy | array math, aggregation, linear algebra, polynomials |
| Math | trigonometry, number patterns |

Each exercise has a short description followed by the solution, so the notebook can be read
top to bottom or jumped into by section.

## Running it

```bash
pip install numpy
jupyter notebook python_hackerrank_practice.ipynb
```

Most cells read their input with `input()`, the same way HackerRank submits test cases — so when
running a cell interactively you'll be prompted for input in the same order shown in the
problem's sample input.
